# Проект "МОС 221"

**Краткое описание решения:** Проект "МОС 221" - это Python-приложение, которое использует ИИ-агенты для глубокого анализа финансовых и операционных данных предприятий, выявляя аномалии, точки роста и зоны внимания. Результаты анализа визуализируются в интерактивном веб-интерфейсе на React, помогая принимать обоснованные решения в области промышленного развития, инвестиций и налогового планирования. Вся работа ведется с помощью локальных LLM, что обеспечивает безопасность данных.

**Технические особенности:** Python, FastAPI, React, LangChain, Ollama, Pandas, openpyxl, requests, BeautifulSoup4, recharts, Vite, Tailwind CSS.

**Уникальность решения:** Модульная архитектура с ИИ-агентами для автоматического выявления инсайтов и интерактивной визуализацией данных для поддержки принятия решений. Система полностью построена на open-source решениях, что исключает зависимость от сторонних вендоров.

## Преимущества системы

### 1. Глубокий Анализ на Базе ИИ

Система использует продвинутые ИИ-агенты для автоматического выявления аномалий, точек роста, зон внимания и интересных фактов в финансовых и операционных данных предприятий. Это позволяет быстро получать ценные инсайты, которые трудно обнаружить вручную.

### 2. Модульная и Расширяемая Архитектура

Проект построен на модульных принципах, что обеспечивает высокую гибкость и простоту добавления новых аналитических агентов или источников данных. Разделение на API и UI позволяет легко масштабировать систему и разрабатывать компоненты независимо.

### 3. Интерактивная Визуализация Данных

Современный пользовательский интерфейс на React с интерактивными графиками (`recharts`) предоставляет наглядное представление сложных данных, делая их доступными для широкого круга пользователей. Возможность детализации от общих показателей до конкретных компаний и отраслей улучшает понимание ситуации.

### 4. Поддержка Принятия Решений

Предоставляя структурированные инсайты и визуализации, система служит мощным инструментом для поддержки принятия решений в области промышленного развития, инвестиций, управления трудовыми ресурсами и налогового планирования.

### 5. Перспективы Развития

- **Интеграция с реальными данными:** Подключение к реальным базам данных и API для получения актуальной информации о предприятиях.
- **Расширение аналитических моделей:** Добавление новых типов агентов для более глубокого анализа (например, анализ рисков, прогнозирование, сценарное моделирование).
- **Улучшение взаимодействия с LLM:** Использование более мощных и специализированных языковых моделей для повышения точности и глубины анализа.
- **Персонализация:** Разработка функций для настройки аналитических отчетов под конкретные нужды пользователей.

## Пользовательский интерфейс (UI)

Проект включает в себя интерактивный пользовательский интерфейс, разработанный на React, для визуализации и анализа данных. UI предоставляет следующие возможности:

### Основные Функции

- **Главный дашборд:** Отображает сводную аналитику по всем компаниям, включая общие финансовые показатели (выручка, прибыль) и ключевые выводы, сгенерированные ИИ-агентами (критические события, точки роста, зоны внимания).
- **Анализ по компаниям и отраслям:** Пользователь может переключаться между двумя режимами анализа: на уровне отдельных компаний и на уровне отраслей в целом.
- **Детализация:**
  - **Страница компании:** Углубленный анализ отдельной компании с подробными финансовыми графиками и персональными ИИ-инсайтами.
  - **Страница отрасли:** Сравнительный анализ компаний внутри одной отрасли, выявление лидеров и отстающих, а также отраслевых тенденций.
- **Интерактивные графики:** Визуализация данных с помощью библиотеки `recharts` для наглядного представления динамики и структуры показателей.

## Структура Проекта

Проект организован по модульному принципу для улучшения читаемости и поддерживаемости:

- `src/`: Содержит исходный код Python.
  - `src/excel_processor/`: Скрипты для обработки Excel-файлов.
    - `extract_headers.py`: Скрипт для извлечения заголовков из Excel-файла в JSON.
  - `src/web_scraper/`: Скрипты для парсинга веб-страниц.
    - `parse_spark.py`: Скрипт для извлечения данных с сайта Spark-Interfax.
- `data/`: Содержит демонстрационные и временные файлы.
  - `data/company/data_company.json`: Демонстрационные данные по компаниям в формате JSON.
  - `data/excel_output/`: Выходные JSON-файлы, полученные из Excel.
  - `data/web_output/`: Выходные JSON-файлы, полученные с веб-сайтов.
  - `data/temp/`: Временные файлы, используемые в процессе работы.
- `api/`: Содержит код FastAPI приложения.
  - `api/main.py`: Основной файл API, определяющий RESTful эндпоинты для взаимодействия с UI.
  - `api/orchestrator.py`: Оркестратор, управляющий работой агентов и преобразующий данные.
  - `api/models.py`: Pydantic модели данных, соответствующие структуре UI.
  - `api/data_loader.py`: Модуль для генерации демонстрационных данных для API.
  - `api/agents/`: Директория с модулями ИИ-агентов, сгруппированными по типу анализа.
    - `api/agents/base.py`: Базовый класс для аналитических агентов, содержащий общую логику.
- `ui/`: Содержит код React UI приложения.
  - `ui/App.tsx`: Главный компонент приложения.
  - `ui/services/`: Сервисы для взаимодействия с API и LLM.
  - `ui/components/`: Переиспользуемые компоненты.
  - `ui/pages/`: Страницы приложения.
  - `ui/index.html`, `ui/index.tsx`: Точка входа UI.

## Система Агентов (Agent System)

Система включает в себя несколько групп агентов, каждая из которых отвечает за свой аспект анализа. Агенты теперь работают со структурированными Pydantic-моделями данных, что обеспечивает типобезопасность и упрощает интеграцию.

### 1. Агенты извлечения данных (`api/agents/enterprise/agents.py`)

Эти агенты отвечают за извлечение конкретных числовых и текстовых данных из неструктурированного текста.

- **RevenueAgent**: Извлекает данные о выручке.
- **NetProfitAgent**: Извлекает данные о чистой прибыли.
- **EmployeeCountAgent**: Извлекает данные о общей численности персонала.
- **MoscowEmployeeCountAgent**: Извлекает данные о численности персонала в Москве.
- **PayrollTotalAgent**: Извлекает данные о общем фонде оплаты труда (ФОТ).
- **PayrollMoscowAgent**: Извлекает данные о ФОТ в Москве.
- **AvgSalaryTotalAgent**: Извлекает данные о средней зарплате по компании.
- **AvgSalaryMoscowAgent**: Извлекает данные о средней зарплате в Москве.
- **TaxesMoscowNoExciseAgent**: Извлекает данные о налогах в бюджет Москвы.
- **ProfitTaxAgent**: Извлекает данные о налоге на прибыль.
- **PropertyTaxAgent**: Извлекает данные о налоге на имущество.
- **LandTaxAgent**: Извлекает данные о налоге на землю.
- **NDFLAgent**: Извлекает данные по НДФЛ.
- **TransportTaxAgent**: Извлекает данные о транспортном налоге.
- **OtherTaxesAgent**: Извлекает данные о прочих налогах.
- **ExciseTaxesAgent**: Извлекает данные по акцизам.
- **InvestmentsMoscowAgent**: Извлекает данные об инвестициях в Москве.
- **ExportVolumeAgent**: Извлекает данные об объеме экспорта.
- **PropertyComplexAgent**: Извлекает данные об имущественно-земельном комплексе.

### 2. Анализ по конкретному предприятию (`api/agents/enterprise/analysis_agents.py`)

Эта группа агентов проводит базовый анализ финансовых и операционных показателей для одной компании.

- **CriticalEventsAgent**: Выявляет критические события (падение выручки, убытки, сокращение персонала).
- **GrowthPointsAgent**: Находит точки роста (рост рентабельности, экспорт, инвестиции).
- **AttentionZonesAgent**: Определяет зоны внимания (зависимость от заказчика, рост затрат).
- **InterestingFactsAgent**: Находит интересные факты (рекордные показатели, уникальные продукты).

### 3. Анализ по предприятиям отрасли (`api/agents/industry/analysis_agents.py`)

Сравнение компаний в пределах одной отрасли.

- **IndustryCriticalEventsAgent**: Выявляет критические события в отрасли (например, общее снижение выручки).
- **IndustryGrowthPointsAgent**: Определяет лидеров отрасли по производительности и росту.
- **IndustryAttentionZonesAgent**: Находит зоны внимания (например, высокая налоговая нагрузка в отрасли).
- **IndustryInterestingFactsAgent**: Выявляет интересные факты (например, концентрация рынка).

### 4. Анализ по размеру предприятия (`api/agents/size/analysis_agents.py`)

Группировка и анализ компаний по размеру (микро, малые, средние, крупные).

- **SizeCriticalEventsAgent**: Выявляет критические события в группах (например, снижение рентабельности у микропредприятий).
- **SizeGrowthPointsAgent**: Находит точки роста (например, опережающий рост экспорта у малых фирм).
- **SizeAttentionZonesAgent**: Определяет зоны внимания (например, снижение производительности труда у средних предприятий).
- **SizeInterestingFactsAgent**: Находит интересные факты (например, вклад крупных компаний в налоговые поступления).

### 5. Анализ трудовых ресурсов (`api/agents/labor/analysis_agents.py`)

Анализ показателей, связанных с персоналом.

- **LaborCriticalEventsAgent**: Выявляет критические события (например, снижение численности сотрудников).
- **LaborGrowthPointsAgent**: Находит точки роста (например, рост производительности труда).
- **LaborAttentionZonesAgent**: Определяет зоны внимания (например, рост ФОТ без увеличения выручки).
- **LaborInterestingFactsAgent**: Находит интересные факты (например, самая высокая средняя з/п в отрасли).

### 6. Географический анализ (`api/agents/geo/analysis_agents.py`)

Анализ в разрезе округа, района, адреса производства.

- **GeoCriticalEventsAgent**: Выявляет критические события (например, регион с падением инвестиций).
- **GeoGrowthPointsAgent**: Находит точки роста (например, новый кластер промышленности).
- **GeoAttentionZonesAgent**: Определяет зоны внимания (например, низкая загрузка мощностей в локации).
- **GeoInterestingFactsAgent**: Находит интересные факты (например, концентрация экспортных предприятий).

### 7. Анализ инвестиций и экспорта (`api/agents/finance/analysis_agents.py`)

Анализ финансовых потоков, связанных с инвестициями и экспортом.

- **FinanceCriticalEventsAgent**: Выявляет критические события (например, прекращение экспортных поставок).
- **FinanceGrowthPointsAgent**: Находит точки роста (например, выход на новые рынки).
- **FinanceAttentionZonesAgent**: Определяет зоны внимания (например, зависимость от одного импортёра).
- **FinanceInterestingFactsAgent**: Находит интересные факты (например, экспорт в >10 стран).

### 8. Анализ производственных мощностей (`api/agents/production/analysis_agents.py`)

Анализ использования производственных ресурсов.

- **ProductionCriticalEventsAgent**: Выявляет критические события (например, загрузка мощностей <50%).
- **ProductionGrowthPointsAgent**: Находит точки роста (например, запуск новой линии).
- **ProductionAttentionZonesAgent**: Определяет зоны внимания (например, устаревшие площади).
- **ProductionInterestingFactsAgent**: Находит интересные факты (например, переход на стандартизированную продукцию).

### 9. Анализ по видам продукции (`api/agents/product/analysis_agents.py`)

Анализ на основе классификаторов продукции.

- **ProductCriticalEventsAgent**: Выявляет критические события (например, исчезновение продукта с рынка).
- **ProductGrowthPointsAgent**: Находит точки роста (например, новый продукт в топе продаж).
- **ProductAttentionZonesAgent**: Определяет зоны внимания (например, высокая себестоимость сегмента).
- **ProductInterestingFactsAgent**: Находит интересные факты (например, редкий экспортируемый товар).

### 10. Анализ связей и структуры владения (`api/agents/ownership/analysis_agents.py`)

Анализ на основе связей между компаниями.

- **OwnershipCriticalEventsAgent**: Выявляет критические события (например, банкротство материнской компании).
- **OwnershipGrowthPointsAgent**: Находит точки роста (например, интеграция внутри холдинга).
- **OwnershipAttentionZonesAgent**: Определяет зоны внимания (например, зависимость от головной компании).
- **OwnershipInterestingFactsAgent**: Находит интересные факты (например, транснациональные структуры).

### 11. Анализ налоговой нагрузки (`api/agents/tax/analysis_agents.py`)

Анализ налоговых отчислений.

- **TaxCriticalEventsAgent**: Выявляет критические события (например, рост налоговой нагрузки >30%).
- **TaxGrowthPointsAgent**: Находит точки роста (например, оптимизация налогообложения).
- **TaxAttentionZonesAgent**: Определяет зоны внимания (например, рост доли НДФЛ при снижении ФОТ).
- **TaxInterestingFactsAgent**: Находит интересные факты (например, налог на прибыль ниже среднего по отрасли).

### Источник данных в UI

Для демонстрации функционала UI использует набор демонстрационных данных, сгенерированных сервисом `ui/services/mockDataService.ts`. Этот сервис имитирует получение реальных данных и содержит предопределенные аномалии, что позволяет тестировать и показывать работу ИИ-агентов по их выявлению.

## Сборка и Запуск

### 1. Установка Зависимостей

#### Python зависимости (для API)

Для установки всех необходимых библиотек Python используйте `uv`. Сначала синхронизируйте основные зависимости, затем установите дополнительные для веб-скрейпинга и API:

```bash
uv sync
uv pip install requests beautifulsoup4 fastapi uvicorn langchain-ollama langchain-core langchain
```

#### Node.js зависимости (для UI)

**Предварительные требования:** Убедитесь, что у вас установлен Node.js (рекомендуется версия 20 или выше).

Перейдите в директорию `ui/` и установите зависимости:

```bash
cd ui
npm install
cd ..
```

### 2. Запуск Ollama

Ollama — это платформа для запуска больших языковых моделей локально.

1.  **Установка Ollama:**
    Скачайте и установите Ollama для вашей операционной системы с официального сайта: [ollama.com](https://ollama.com/).

2.  **Запуск Ollama:**
    После установки запустите Ollama. Обычно это делается через приложение (на macOS/Windows) или командой в терминале:

    ```bash
    ollama serve
    ```

3.  **Загрузка модели:**
    Загрузите модель `gemma:3b`, которая используется в проекте:
    ```bash
    ollama pull gemma:3b
    ```

### 3. Запуск API

Запустите FastAPI приложение:

```bash
python -m api.main &
```

API будет доступно по адресу `http://0.0.0.0:8000`.

### 4. Запуск UI

1.  **Настройка GEMINI_API_KEY (опционально, если используется реальный API):**
    Создайте файл `.env.local` в директории `ui/` и добавьте ваш Gemini API ключ:

    ```
    GEMINI_API_KEY=ВАШ_GEMINI_API_KEY
    ```

    _Примечание: В текущей версии UI используются демонстрационные данные и сервисы, поэтому реальный ключ API не требуется для запуска._

2.  **Запуск UI приложения:**
    Перейдите в директорию `ui/` и запустите приложение в режиме разработки:
    ```bash
    cd ui
    npm run dev &
    cd ..
    ```
    UI будет доступно по адресу, указанному в выводе команды (обычно `http://localhost:3000`).

### Использование Скриптов Модулей (Python)

- **Извлечение заголовков из Excel:**

  ```bash
  python src/excel_processor/extract_headers.py base.xlsx
  # Результат будет сохранен в data/excel_output/base_headers.json
  # Можно указать другой путь для сохранения:
  # python src/excel_processor/extract_headers.py base.xlsx my_custom_headers.json
  ```

- **Парсинг данных с Spark-Interfax:**
  ```bash
  python src/web_scraper/parse_spark.py https://spark-interfax.ru/statistics/region/45000000000
  # Результат будет сохранен в data/web_output/spark_regions.json
  # Можно указать другой путь для сохранения:
  # python src/web_scraper/parse_spark.py https://spark-interfax.ru/statistics/region/45000000000 my_custom_regions.json
  ```

- **Обработка Данных:** Для работы с табличными данными и файлами Excel предпочтительно использовать библиотеки `pandas` и `openpyxl`.
- **Веб-скрейпинг:** Для работы с веб-страницами используются `requests` и `beautifulsoup4`.
- **Точка Входа:** Файл `main.py` является основной точкой входа в приложение.
- **Организация кода:** Код разделен на модули в директории `src/`, а генерируемые данные сохраняются в соответствующие поддиректории в `data/`.
