# Проект "mos"

## Обзор Проекта

Проект "mos" представляет собой Python-приложение, предназначенное для обработки данных из файлов Excel (`base.xlsx`) и парсинга веб-страниц (Spark-Interfax). Основная логика приложения находится в файле `main.py`.

## Стек Технологий

*   **Язык программирования:** Python (требуется версия 3.13 или выше)
*   **Управление зависимостями:** `uv` (используется `pyproject.toml` для определения зависимостей)
*   **Основные библиотеки:**
    *   `pandas`: Для работы с данными, особенно табличными.
    *   `openpyxl`: Для чтения и записи файлов Excel.
    *   `requests`: Для выполнения HTTP-запросов к веб-сайтам.
    *   `beautifulsoup4`: Для парсинга HTML-содержимого.

## Структура Проекта

Проект организован по модульному принципу для улучшения читаемости и поддерживаемости:

*   `src/`: Содержит исходный код Python.
    *   `src/excel_processor/`: Скрипты для обработки Excel-файлов.
        *   `extract_headers.py`: Скрипт для извлечения заголовков из Excel-файла в JSON.
    *   `src/web_scraper/`: Скрипты для парсинга веб-страниц.
        *   `parse_spark.py`: Скрипт для извлечения данных с сайта Spark-Interfax.
*   `data/`: Содержит все генерируемые данные и временные файлы.
    *   `data/excel_output/`: Выходные JSON-файлы, полученные из Excel.
    *   `data/web_output/`: Выходные JSON-файлы, полученные с веб-сайтов.
    *   `data/temp/`: Временные файлы, используемые в процессе работы.
*   `api/`: Содержит код FastAPI приложения и логику работы ИИ-агентов.
    *   `api/agents/`: Директория с модулями ИИ-агентов, сгруппированными по типу анализа.

## Архитектура ИИ-Агентов

Система ИИ-агентов построена по модульному принципу для обеспечения гибкости и расширяемости.

### 1. Принцип модульности
Агенты сгруппированы в директории внутри `api/agents/` в соответствии с их аналитической задачей. Каждая директория представляет собой независимый аналитический модуль.
- `enterprise`: Анализ по конкретному предприятию.
- `industry`: Сравнительный анализ по отрасли.
- `size`: Анализ в разрезе размера предприятий.
- `labor`: Анализ трудовых ресурсов.
- `geo`: Географический анализ.
- `finance`: Анализ инвестиций и экспорта.
- `production`: Анализ производственных мощностей.
- `product`: Анализ по видам продукции.
- `ownership`: Анализ структуры владения.
- `tax`: Анализ налоговой нагрузки.

### 2. Типы Агентов
Существует два основных типа агентов:
- **Агенты извлечения данных (`.../agents.py`):** Принимают на вход сырой текст и извлекают из него структурированные данные (например, `RevenueAgent`).
- **Агенты-аналитики (`.../analysis_agents.py`):** Принимают на вход структурированные данные в формате JSON и генерируют на их основе аналитические выводы (инсайты), сгруппированные по категориям (критические события, точки роста, зоны внимания, интересные факты).

### 3. Использование базовых классов
Для каждой группы агентов определен свой базовый класс (например, `AnalysisAgent`, `IndustryAnalysisAgent`), который устанавливает общий интерфейс (метод `analyze`) и может содержать общую логику, такую как парсинг ответов от LLM.

### 4. Оркестрация
Для управления сложными цепочками вызовов агентов используется класс-оркестратор (`api/orchestrator.py`). Оркестратор отвечает за подготовку данных для агентов и последовательный вызов необходимых модулей анализа.

### 5. Взаимодействие с LLM
- Для построения цепочек используется синтаксис `prompt | llm` из `langchain_core`.
- Для вызова цепочки используется метод `.invoke()`.
- В аналитических агентах применяется вспомогательный метод `_parse_response` для надежного извлечения JSON из ответа модели, который может содержать markdown-разметку.

## Сборка и Запуск

### Установка Зависимостей

Для установки всех необходимых библиотек используйте `uv`. Сначала синхронизируйте основные зависимости, затем установите дополнительные для веб-скрейпинга:

```bash
uv sync
uv pip install requests beautifulsoup4 fastapi uvicorn langchain-ollama langchain-core
```

### Запуск Основного Приложения

Основной скрипт приложения можно запустить следующей командой:

```bash
python main.py
```

### Использование Скриптов Модулей

*   **Извлечение заголовков из Excel:**
    ```bash
    python src/excel_processor/extract_headers.py base.xlsx
    # Результат будет сохранен в data/excel_output/base_headers.json
    ```

*   **Парсинг данных с Spark-Interfax:**
    ```bash
    python src/web_scraper/parse_spark.py https://spark-interfax.ru/statistics/region/45000000000
    # Результат будет сохранен в data/web_output/spark_regions.json
    ```

## Конвенции Разработки

*   **Версия Python:** Проект требует Python версии 3.13 или выше.
*   **Управление Зависимостями:** Все зависимости проекта должны быть указаны в `pyproject.toml` и управляться с помощью `uv`.
*   **Организация кода:** Код разделен на модули в директории `src/` и `api/`, а генерируемые данные сохраняются в соответствующие поддиректории в `data/`.
